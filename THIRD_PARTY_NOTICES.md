# Third-party components

X-Planner integrates with the following upstream projects. Their names and links are provided for
dependency and provenance review; each remains governed by its own license and terms.

| Component | Purpose | Upstream |
| --- | --- | --- |
| Qwen3.5-VL | vision-language backbone | https://github.com/QwenLM/Qwen3-VL |
| Transformers | model loading and training APIs | https://github.com/huggingface/transformers |
| xDataset | robot multimodal data backend | https://github.com/X-Square-Robot/xDataset |
| lmms-eval | general multimodal evaluation | https://github.com/EvolvingLMMs-Lab/lmms-eval |

Before public release, the maintainers must verify whether any source file in this repository is
copied or derived from upstream code and reproduce every required copyright and license notice.
