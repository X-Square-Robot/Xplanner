# Dataset and benchmark licensing

The published benchmark is
[x-square-robot/xplanner-benchmark](https://huggingface.co/datasets/x-square-robot/xplanner-benchmark).
Its dataset card and
[source ledger](https://huggingface.co/datasets/x-square-robot/xplanner-benchmark/blob/main/metadata/source_ledger.json)
record provenance and explain the upstream terms. The checklist below applies to additional data
exports; the code's MIT license does not cover benchmark media.

Code licensing and data licensing are independent. A dataset name or public download URL does not
by itself grant redistribution rights. Before publishing any media or annotation, add one row for
every source represented in the release and obtain approval from the data owner.
